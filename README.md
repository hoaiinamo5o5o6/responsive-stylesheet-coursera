# Create a Responsive Stylesheet

A Coursera peer-graded project demonstrating a mobile-first layout with tablet and large-screen media queries.

## Responsive breakpoints

- Mobile: each `div` uses 90% of the viewport width.
- Tablet (`min-width: 772px`): each `div` uses 45% width and images are limited to 30% of the viewport height.
- Large screen (`min-width: 998px`): each `div` uses 30% width.
